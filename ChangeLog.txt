# Down Under Gambler's Sweat It Out! Derby '27 - Change Log

## Version 0.2.0 (2026-11-22)

### New Features
- **Developer Mode** (`python app.py --dev`, opens /dev): the art CMS and a screen gallery,
  separate from playing. Every picture the game needs is listed by category (29 of them:
  title, characters, props, the nine venues, event scenery, the map), each with its own
  canvas size (Agent Kevin is 32x48, tall and narrow). Draw, Save, Save As (new version, or
  a starting point for other art), import PNGs, and pick the version used in game. The
  live preview shows the drawing on the real screens it appears on before it's saved
- **Screens tab**: all 45 host and phone screens with four sample players, from the lobby
  to the final reveal, for checking art and layout without playing to that point
- Art drawn in Developer Mode replaces its placeholder box on the TV and phones; anything
  not drawn yet stays an `[ART: ...]` box
- The head-drawing pad gained a colour picker tool

### Packaging / Internal
- Built on APGE 0.3.0 (Developer Mode, art library, shared pixel editor - all added for
  this game). The pixel editor now comes from APGE; /art and static/pixelart.js are gone
- dev.py: the art list and sample screens; venue art ids from rules.venue_art()
- Tests: tests/test_dev.py (every sample screen builds, art list matches the JS) and
  tests/test_dev_browser.py (Playwright drives Developer Mode and loads every screen)

## Version 0.1.0 (2026-11-15)

First playable draft of the design doc's critical path, with placeholder art.

### New Features
- **Character creation**: join with a name (15 letters), draw a 16x16 pixel head on the
  phone (pencil, eraser, fill, mirror, undo), spend 10 skill points on STR / SPD / MCR.
  The first player to finish is the HOST and starts the game from their phone
- **Season**: 13 stops across NZ and Australia in three zones, with a map between stops
- **Gambling events**: Foot Race, Speed Hiking, Fist Fight, Australian Rules Sand Curling,
  Mini Golf, Mascot Race, Sumo Wrestle, Half-Court Shots, Holding A Note. Odds are simulated
  from everyone's stats, bets go up in $Dd 10 steps with a live "On win" preview, and each
  event has a host-screen animation (race lanes, last-one-standing, or turn by turn)
- **Shady Koala**: secret visits (more per zone) selling Bat to Kneecaps, HGH Injection and
  Bribe the Feds. **Kangarules Gambling Commission** frisks negate everything a frisked
  player bought and show it on the big screen
- **Loansharks**: Shrimp and Barbie lend to anyone below the starting cash; they want double
  back at the end
- **Special events**: Mother's Purse, Trading Card Auction, Case or No Case, Ticket Scalping
- **Final results**: standings revealed last place first, then the loans are collected, then
  the winner and awards. The host can start one more game or quit
- **Art tool** at /art: the same pixel editor at 16-64 px, saves PNG and editable .txt

### Packaging / Internal
- Built on APGE 0.2.0 (VIP phone controls, quit, per-game name length, lobby setup in the
  bot harness - all added for this game)
- Tests: rules unit tests, bot matrix (4 bots, every standard scenario, ghosts quitting in
  every input phase), Playwright browser check of every screen
